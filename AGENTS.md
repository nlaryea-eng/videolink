# VideoLink workflow

- This is primarily Neill's Mac application.
- Normal use starts in Apple Shortcuts with Control–Option–Command–V.
- Preserve the shortcut's existing invocation, clipboard flow, player launch,
  and subtitle choices when changing tooling. Do not assume an interactive
  terminal or its PATH is available.
- Prefer a simple native macOS setup. Other platform and backend support is
  secondary; ask before removing existing functionality.
